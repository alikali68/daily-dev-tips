# Sharpen Last, and Sharpen for the Output

Sharpening should be the final step in your retouching workflow, not an early one. Every edit after sharpening — resizing, cropping, exporting, or compressing — changes the pixels the sharpening was tuned for, so halos get exaggerated and fine detail turns crunchy. Finish all retouching first, then resize to the exact output size, and only then apply sharpening tuned for that destination. A file headed for the screen and a file headed for print need different settings, because a screen shows every pixel while print softens detail through ink and paper.

```
Screen export (web / social): Amount 60-80, Radius 0.8-1.0, Detail 30-50
Print export:                  Amount 80-110, Radius 1.2-1.5, Detail 20-30
```

Keep two exports from the same retouched master instead of one sharpened file for everything, and judge the result at 100% zoom on the actual output size — never on a zoomed-out preview.

Why it matters: sharpening tuned to the wrong size or output is the most common reason an otherwise clean retouch looks soft online or harsh in print.
