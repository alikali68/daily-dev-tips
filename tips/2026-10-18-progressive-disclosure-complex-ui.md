# Progressive Disclosure: Stop Showing Users Everything at Once

Complex interfaces don't scare users — everything-visible-at-once interfaces do. Progressive disclosure means showing only the controls, options, and information a user needs at the current step, and hiding the rest behind clear affordances (accordions, "Advanced" toggles, step-by-step wizards). A settings page with 40 options becomes 6 groups; a signup form with 15 fields becomes 3 friendly steps.

Use it where complexity is unavoidable: admin dashboards, checkout flows, onboarding, and configuration screens. The rule of thumb: the primary path should be obvious in under 3 seconds; secondary options reveal themselves exactly when they're relevant. Always make hidden content discoverable — label the trigger honestly ("Show advanced options"), never hide destructive or irreversible actions where users can't find them.

**Why it matters:** Interfaces that disclose progressively test dramatically better — users complete tasks faster, make fewer errors, and rate the product as "simpler" without you removing a single feature.
